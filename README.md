# All tags (HTML, CSS, JavaScript)

Презентация-справочник по основным тегам и конструкциям HTML, CSS и JavaScript.
Наглядное пособие для тех, кто начинает изучать веб-разработку: каждый элемент
показан с примером кода и описанием того, как он работает в браузере.

## 📑 Содержание презентации

**HTML**
- Структура документа — `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- Текстовые теги — заголовки `<h1>`–`<h6>`, абзацы, выделение текста
- Ссылки и изображения — `<a>`, `<img>`
- Списки, таблицы и формы

**CSS**
- Подключение стилей и селекторы
- Цвета, шрифты, отступы
- Основы оформления элементов

**JavaScript**
- Подключение скриптов
- Переменные и функции
- Взаимодействие со страницей
